# 风格库 · 五秒动效演示

## 交付边界

16种风格，每种5.000秒、30fps、竖版9:16、静音。PNG封面取自对应视频；客户端完整画幅显示，悬停循环，离开停止并恢复封面。所有素材本地生成，无远程字体、外部服务或真实品牌。

这些是人工设计的风格演示，不是当前项目成片，也不保证自动生成的视频具有同样的内容编排。演示不通过用户作品注册表渲染，避免改写用户项目。

## 验收标准

- 不共用标题+三角形卡片布局，每种有独立构图、主视觉、动作语言。
- 1080×1920设计画布；输出720×1280 H.264 yuv420p，150帧、无音轨、faststart。
- 不用满屏颗粒和扫光掩盖无动作，保留清晰的字、轮廓与真实的留白。
- 主标题在库卡片里可读，主体占画面至少一半，封面在2秒处为完整构图。
- 首帧非黑，0–0.6秒建立，0.6–3.8秒展示主体动作，3.8–5秒保留阅读与次级运动。
- 独立查看真实封面及多个时间点，不用技术规格通过替代视觉验收。

## 三组画面方向

### 纸与墨

贴纸：奶油白与钴蓝、珊瑚色剪贴手机与漂浮标签。
拼贴：撕边报纸、城市剪影、月亮、红色编辑标记。
线稿：建筑植物或生活器物，墨线逐笔生长。
手绘：帧格抖线、夸张运动角色，暖黄与橙黑。
汉字：黑白朱红、纪念碑式大字与植物笔画。

### 结构与体积

矢量：模组化矢量机器与色块协作。
等距：清楚的三面体积、微型系统与流动连接。
3D：投影网格的曲面体、棚拍明暗、真实轮廓与遮挡；不宣称PBR。
形变：连续轮廓插值，形状本身有演化，不只是箭头。
包豪斯：瑞士式海报、大数字与原色构成。

### 光与像素

HUD：有层级的仪器刻度、遥测轨迹、信号扫描。
液态：明亮干净的光滑流体与高光。
霓虹：透视公路、网格山脊、条纹落日。
玻璃：层叠棱镜、折光边缘与柔光。
像素：手绘像素火箭、星体和火焰，整数格轮廓。

### 证据与账本

华尔街：深蓝斜纹织物舞台、奶油金巨数、白底原文卡与荧光黄高亮、同一坐标系的柱子。
